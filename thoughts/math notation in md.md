## Quick Usage Notes

1. **Inline Math**: Enclose code in single dollar signs: `$E = mc^2$`.
2. **Display Math**: Enclose code in double dollar signs on separate lines:
   ```latex
   $$
   \int_{-\infty}^{\infty} e^{-x^2} \, dx = \sqrt{\pi}
   $$
   ```
3. **Escaping Characters in Plain Text**: If you are not in math mode and want to display characters like `<`, `>`, or `&`, use the corresponding HTML entities (`&lt;`, `&gt;`, `&amp;`) to avoid Markdown parsing issues.
